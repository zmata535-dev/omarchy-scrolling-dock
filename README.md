# Omarchy Scrolling Dock

A user-level clone of Omarchy's Quickshell dock, adapted for Hyprland's scrolling layout.

## Features

- Shows on scrolling workspaces and hides after the pointer leaves the dock and edge trigger.
- Gives every open window its own icon, ordered by screen position.
- Highlights the focused window and shows app/window-title tooltips.
- Matches the current bar background mode and Hyprland window-border colors.
- Includes an app launcher and a session-menu button.

## Install

Copy these files into `~/.config/omarchy/plugins/zm.dock/`, then enable `zm.dock` in the Omarchy shell. The session button opens the System menu through `omarchy.menu`.
